The Duly API and MCP server

The engine behind the calculators, as a JSON API and as tools your AI assistant can call. No SDK, no signup to try it.

Connect an AI assistant (MCP)

Duly runs a remote MCP server at https://duly.nz/mcp (Streamable HTTP). Free use needs no key.

Claude Code

claude mcp add --transport http duly https://duly.nz/mcp

Claude, ChatGPT and other apps with custom connectors

Add a custom connector with the URL https://duly.nz/mcp. With a paid key use https://duly.nz/mcp/k/<your key>.

Cursor, Windsurf, VS Code and others

{
  "mcpServers": {
    "duly": { "url": "https://duly.nz/mcp", "headers": { "Authorization": "Bearer duly_live_…" } }
  }
}
ToolWhat it does
nz_deadlineWork out the date that is N working days after (or before) a date under a specific New Zealand Act or standard contract.
nz_count_working_daysCount the working days after one date up to and including another, under a specific New Zealand definition of "working day".
nz_is_working_daySay whether a date is a working day under a specific New Zealand definition, and if not, why (weekend, which public holiday, the Christmas period, or an anniversary day)..
nz_calendar_deadlineAdd calendar days to a date (e.g.
nz_public_holidaysList New Zealand public holidays for a year (2010–2052), including Mondayised observances, Matariki, and provincial anniversary days with the rule each follows..
nz_working_day_definitionsList every definition of "working day" Duly supports, with its statute and section, what it excludes, and common timeframes.

REST API

Base URL https://duly.nz/v1. Every endpoint accepts GET with query parameters or POST with JSON. Send your key as Authorization: Bearer <key>; without one you are on the free tier.

EndpointParameters
/v1/deadlineregime, from, days, optional direction (after|before), start_rule (after|on), province, trace
/v1/countregime, from, to, optional province, trace
/v1/is-working-dayregime, date, optional province
/v1/calendar-daysfrom, days, optional roll=next-working-day, regime, province
/v1/holidaysyear, optional province, format=ics
/v1/regimes, /v1/regimes/{id}Definitions, rules, citations and common timeframes
/v1/batchPOST an array of {"op": "deadline", …} (Pro: 100 per call; Platform: 500)

Embed the calculator

Put a calculator on your own site. It is free with a small “Counted by Duly” credit.

<div data-duly="oia"></div>
<script src="https://duly.nz/embed.js" async></script>

Use any regime id from the table above for data-duly.

Limits and plans

Free: 20 requests a minute per IP address, for personal use and evaluation. Pro and Platform keys raise the limit, allow commercial use and unlock batch requests. See pricing.

Accuracy

Every response includes the citation, the engine version and the date the rules were last checked. Read how Duly checks itself.
