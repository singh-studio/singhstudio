Questions

Before you buy.

Which Squarespace plans do they work on?

Any plan that runs JavaScript: Core, Plus and Advanced on the current plans, and Business, Commerce Basic and Commerce Advanced on older ones. The Basic and Personal plans block custom scripts, so the plugins can’t run there. They work on Squarespace 7.0 and 7.1.

Is it a subscription?

No. Each plugin is a single payment, and every update in its 1.x version is included. The licence covers one website, or any number of websites with the unlimited licence.

How do I install one?

You paste one file into a Squarespace Code block and change one setting, usually the address of the blog or page it reads. Each download comes with an install guide written for whoever looks after the website, and a setup check that tells you what it found.

Can you install it for me?

Prefer it done for you? I’ll install and set up any plugin on your site for US$79, including tagging a first batch of content so it looks full on day one.

What if it doesn’t work on our site?

Email me with the page address and I’ll help you get it working. Because the plugins are digital downloads, purchases aren’t refundable, which is why every plugin has a live demo to try first.

Do the plugins collect any data?

No. They read your own site’s public content and keep a copy in each visitor’s browser to load faster. There’s no tracking and nothing is sent to an outside server.
