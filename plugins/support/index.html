Support

Help when you need it

Find your downloads

Open your Lemon Squeezy receipt and choose “View downloads” or “View Order”. Lost the email? Open My Orders and enter the email address you used at checkout. Lemon Squeezy will email you a sign-in link so you can access your downloads and order history.

Start with the install guide

Download and unzip your purchase, then open Install guide.html. If you bought the whole library, open the folder for the plugin you want to install first. You can also read the guides here.

Ask for help

Email kris@singhstudio.co.nz and I’ll usually reply within two working days, often sooner. It helps if you include the address of the page where the plugin is installed, and a screenshot of its setup check panel (each install guide shows how to open it).

Done-for-you install

Prefer it done for you? I’ll install and set up any plugin on your site for US$79, including tagging a first batch of content so it looks full on day one. Email me the page you want it on.

Updates

Updates in each plugin’s 1.x version are free. When one comes out you’ll get an email with the new file, and you replace the old paste with the new one. Your settings live on the first line of the paste, so keep that line.

Refunds

The plugins are digital downloads, so purchases aren’t refundable. If one isn’t working on your site, email me with the page address and I’ll help you get it working. The live demos on every plugin page are there so you can try before you buy, and the full terms are on the licence page.

Before you email

  • The plugins need a Squarespace plan that runs JavaScript (Core, Plus or Advanced, or the older Business and Commerce plans).
  • Squarespace doesn’t run scripts inside the editor, so check the live page in a private window.
  • Don’t paste the code into Design → Custom CSS. It goes in a Code block.
