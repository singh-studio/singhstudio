Putting Laurel on a screen.

Each of these takes ten to thirty minutes, and none needs anyone technical. If you get stuck, email me a photo of what you’re seeing.

On a TV

In the editor, go to Save & publish and download the file For a TV. It’s a single file with everything inside it. Then pick whichever of these suits your clubhouse.

A laptop or mini PC (simplest, works offline)

  1. Copy the TV file onto the computer, from a USB stick or by email.
  2. Plug the computer into the TV with an HDMI cable.
  3. Double-click the file. It opens in the web browser (Chrome or Edge are best).
  4. Click once, or press F, for full screen.
  5. Stop the computer going to sleep. On Windows: Settings → System → Power, and set the screen and sleep times to Never. On a Mac: System Settings → Lock Screen, and set the display to never turn off.

To have it start by itself whenever the computer turns on (Windows): press Win+R, type shell:startup, and in the folder that opens make a shortcut with this target, using your own file’s location: "C:\Program Files\Google\Chrome\Application\chrome.exe" --kiosk "C:\Honours\our-club-honours-tv.html"

A small fanless mini PC tucked behind the TV is the tidiest version of this, and it’s what I’d buy if the club doesn’t have a spare laptop.

A streaming stick or Android TV box

These need the board to be on your website first (see below), because they open web addresses rather than files.

  1. Install a web browser on the stick. Most streaming sticks offer one in their app store; a kiosk browser app is ideal because it can open full screen and reopen after a power cut.
  2. Open your board’s web address with #screen on the end, for example https://yourclub.co.nz/honours/#screen.
  3. Set the browser to full screen and to open that address when it starts.

The board checks your website every ten minutes for a newer file, so when you upload new names, the TV picks them up by itself.

The TV’s own web browser

Many smart TVs have a browser. Open your board’s web address with #screen on the end. It works, but TV browsers vary and some switch themselves off after a while, so the first two options are more dependable.

Portrait screens

Mount the TV on its side and set the computer’s display to portrait (Windows: Settings → System → Display → Display orientation → Portrait). Laurel notices and lays the boards out tall, like a real honours board.

On your website

Download the file For your website. It’s one page with every board, a search box and a page for every person.

If your web host lets you upload files

Most hosting does: cPanel’s file manager, FTP, or your host’s own uploader. Make a folder called honours, upload the file into it and rename it index.html. Your board is now at yourclub.co.nz/honours/.

If you don’t have hosting, or your site is built on Squarespace or Wix

Website builders like Squarespace and Wix can’t host a file like this themselves, so put it on a free host and link to it.

  1. Make a free account at Netlify.
  2. Put the website file in a folder on your computer and rename it index.html.
  3. In Netlify, choose to deploy manually and drag that folder onto the page. You’ll get a web address straight away.
  4. Add a link to that address in your club website’s menu. On Squarespace or Wix you can also show it inside a page with an embed block.

Your web person can point a tidy address like honours.yourclub.co.nz at it later.

WordPress

WordPress’s media library won’t accept web pages, so upload the file with your host’s file manager as above, or use the Netlify route and link to it.

Then add the QR code

Once the board is live, paste its address into Step 1 → Your honours page on the web in the editor, and download the TV file again. The TV now shows a QR code members can scan to look themselves up.

On a touchscreen

Download the file For a touchscreen. It plays the slideshow until someone touches it, lets them search, then goes back to the slideshow after 90 seconds without a touch.

  • A Windows touchscreen or all-in-one PC: open it in Chrome’s kiosk mode, as in the TV tip above, so nobody can wander off to other websites.
  • An Android tablet or touchscreen: use a kiosk browser app and point it at the file, or at your board’s web address with #kiosk on the end.

Getting the names in

Typing

Click a cell and type. Enter moves down a row and adds a new one at the bottom. Everything saves as you go, and Ctrl+Z undoes.

From a spreadsheet

Select the year and name cells in Excel or Google Sheets, copy, click the first cell in Laurel and paste. The rows land in place, starting from the cell you clicked.

From a typed list

Use Paste a list… on any board. It understands lines like 1987 J. Smith, 1987 – J. Smith and J. Smith (1987), and shows you how it read them before adding them.

A whole club at once

Save a spreadsheet as CSV with these columns, then use Open a saved file (or Import a spreadsheet on the boards step):

Hole in One2024Ana Tupou7th hole

From photos of your old boards

Photograph each board straight on, in good light. Type them up, or ask an AI assistant to turn a photo into lines of year name, and then check every line against the photo before pasting: lettering on old boards is easy to misread. Or send me the photos and I’ll do it.

Teams, gaps and odd entries

  • Pairs and teams: separate names with & or /. For bowls fours and rowing crews, tick Team on the name column, and names separated by commas each get the honour.
  • Years with no winner: type Not contested, Vacant or War years. They show quietly on the board and aren’t treated as people.
  • Notes in brackets, like J. Smith (skip), are shown but ignored when matching people.

Next season

  1. Open the editor. Your boards are where you left them. On a different computer, use Open a saved file and choose your backup or any board file.
  2. Add the new names. They get a small mark and a place on this year’s honours slide.
  3. Download the files again and replace the old ones on the TV and website.
  4. Download a fresh backup and keep it somewhere the next secretary can find it.

If something’s not right

The TV shows a plain list instead of the slideshow

The browser is too old to run Laurel, so it falls back to a plain list of every board. Use a current version of Chrome, Edge, Firefox or Safari.

The screen goes black after a while

That’s the computer or the TV saving power. Set the computer’s screen and sleep times to Never, and turn off any power saving or auto standby on the TV.

There’s no QR code on the TV

Add your website address in Step 1 of the editor and download the TV file again.

Pasted names went into the wrong columns

Press Ctrl+Z, click the cell where the first year should go, and paste again. Or use Paste a list…, which shows you the columns before anything changes.

My work has disappeared from the editor

Browsers sometimes clear what sites have saved. Open your latest backup or board file with Open a saved file. This is why the editor reminds you to keep a backup.
